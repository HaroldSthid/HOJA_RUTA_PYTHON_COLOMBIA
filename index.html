Guía de Instalación y Entorno de Desarrollo

Paso a paso para configurar tu entorno local o en la nube antes de comenzar a escribir código en Python 3.12+.

1. Instalación de Python 3.12+

Descarga el instalador oficial desde python.org. En Windows, asegúrate de marcar la casilla "Add Python.exe to PATH" al inicio.

2. Editor Visual Studio Code

Instala VS Code y añade la extensión oficial de Python para autocompletado, resaltado de sintaxis y depuración integrada.

3. Cuadernos en Google Colab

Si no puedes instalar programas locales, utiliza Google Colab para ejecutar cuadernos interactivos en la nube directamente desde tu navegador.

Manual del Estudiante Exitoso

Estrategias pedagógicas y hábitos recomendados por mentores de la comunidad para acelerar tu aprendizaje.

1. Acepta el error como tu aliado

Un mensaje de error (Traceback) no significa que fallaste; significa que el intérprete te está dando una pista exacta de lo que necesita corregirse.

2. Consistencia sobre intensidad

Estudiar y escribir código durante 30 minutos todos los días genera un anclaje mental superior a pasar 6 horas seguidas un solo día de la semana.

3. Escribe en papel primero

Ante un problema lógico complejo, apaga el computador y diseña los pasos en un cuaderno usando pseudocódigo o diagramas sencillos.

4. Comparte y pregunta en comunidad

Ningún programador profesional trabaja aislado. Apóyate en los canales comunitarios para resolver bloqueos técnicos.

Guía de Diagnóstico de Errores Comunes

Aprende a leer y solucionar los errores más frecuentes que arroja la consola de Python.

SyntaxError

Causa: Falta un carácter clave como dos puntos (:), un paréntesis de cierre o comillas.
Solución: Revisa la línea indicada en el reporte.

IndentationError

Causa: Mal uso o mezcla de espacios y tabulaciones en la sangría del bloque de código.
Solución: Usa siempre 4 espacios uniformes por nivel.

NameError

Causa: Intentas usar una variable o función que aún no ha sido declarada o tiene error tipográfico.
Solución: Verifica el nombre exacto.

TypeError

Causa: Operación entre tipos incompatibles (ej. sumar un texto con un número entero sin convertirlo).
Solución: Usa str() o int() para moldear datos.

Terminal & Git Cheat Sheet

Resumen práctico con los comandos esenciales de consola y control de versiones.

Navegación en Consola (Bash/CMD)

pwd — Muestra la ruta actual.
ls / dir — Lista archivos y carpetas.
cd carpeta — Entra a un directorio.
mkdir nueva — Crea un directorio.

Control de Versiones (Git Básico)

git init — Inicializa repositorio local.
git status — Muestra archivos modificados.
git add . — Prepara cambios para guardar.
git commit -m "msg" — Guarda versión local.

Sincronización Remota (GitHub)

git remote add origin URL — Conecta con remoto.
git push -u origin main — Sube la rama principal.
git pull — Descarga actualizaciones del servidor.
